# Standup index

This page is for humans. The **setup air traffic control (ATC)** agent loads [`skills/team-onboarding/SKILL.md`](../skills/team-onboarding/SKILL.md). Seats load official herdr + agent-behavior.

1. Design: project type; starter roster; extra seats/skills; check our [loop](conductor-loop.md) (or proposed `conduct` / AGENTS edits). Stay here until you are comfortable. Say **ready to build** before Herdr.
2. Write skills: installer `--repo`, AGENTS snippet, roster markdown. Apply any loop edits.
3. Herdr: named workspace and tabs. **You** start the lead CLI, then the rest.
4. Onboard the lead like any seat: official herdr + agent-behavior ([`examples/onboard-ack.md`](../examples/onboard-ack.md)).
5. Lead onboards the rest with those **same two skills**. Repeat team-onboarding for each new workspace.

Day to day (swap, new occupant): **agent-behavior** pane onboard — not team-onboarding.
